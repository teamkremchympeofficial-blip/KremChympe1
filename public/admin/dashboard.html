Admin Login

Enter the admin passcode to manage tour guide Telegram Chat IDs.

Telegram Chat ID Manager

For each tour, view, change, or remove the assigned guide's Telegram Chat ID. Changes apply to new bookings immediately.

Removing a Chat ID stops new booking notifications for that tour until a new one is added. Existing bookings are unaffected. Deleting a tour removes it from this dashboard and the booking page entirely — past bookings are unaffected, but this cannot be undone. Bot token, bot settings, and message templates cannot be changed from this dashboard.
